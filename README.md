# Viscera - Video Clipping Tool

A web-based video clipping tool built with Remotion, React, and Vite.

## Features

- Video playback with start and end time controls
- Simple and intuitive interface
- Built with modern web technologies

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

### Development

To start the development server:

```bash
npm run dev
```

To start the Remotion studio:

```bash
npm run start
```

### Building

To build the project:

```bash
npm run build
```

## Usage

1. Enter a video URL in the input field
2. Set the start time (in seconds)
3. Set the end time (in seconds) if you want to clip the video
4. The video will play according to your specified time range

## Debugging

The project includes VS Code launch configurations for debugging:
- "Launch Chrome against localhost" - For debugging the web application
- "Debug Remotion Preview" - For debugging Remotion-specific functionality
